## 一、可行性分析

### 1.1 SOTABand 平台能力匹配

| 需求 | SOTABand 能力 | 匹配度 |
|------|--------------|--------|
| 结构化配方数据管理 | 数据集空间（CSV/JSON/文本多模态数据） | ✅ 完全支持 |
| 多特征预测模型 | 工具注册 → 自动生成代码 → 训练模型 | ✅ 完全支持 |
| 成分交互分析 | LLM 辅助特征工程 + 工具参数化 | ✅ 支持 |
| 预警输出 | 工具执行 → result-summary card 展示 | ✅ 支持 |
| 模型持久化 | models/ 目录 + 工具内加载 | ✅ 支持 |
| 配方历史追溯 | 数据集版本管理 | ✅ 支持 |

### 1.2 技术可行性

**特征维度**（每个配方样本包含）：

| 特征类别 | 具体特征 | 数据类型 |
|---------|---------|---------|
| 乳化体系 | 乳化剂类型、HLB值、油相比例、水相比例 | 分类 + 数值 |
| 理化指标 | pH值、粘度、密度、表面张力 | 数值 |
| 成分列表 | 各成分名称、浓度、功能类别 | 文本 + 数值 |
| 成分交互 | 两两成分之间的已知相互作用标签 | 分类（配伍/拮抗/协同/不兼容） |
| 环境因素 | 温度、湿度、光照（加速老化测试条件） | 数值 |
| 稳定性标签 | 分层天数、析出天数、变色程度（目标变量） | 数值 + 分类 |

**模型选型**：
- **基础方案**：Random Forest / XGBoost（表格数据，可解释性强）
- **进阶方案**：LightGBM + SHAP（特征重要性分析）
- **高级方案**：多任务神经网络（同时预测分层、析出、变色三个维度）

### 1.3 数据来源

本项目的训练和演示数据全部由**配方稳定性模拟数据集构建器**生成，基于以下物理化学规则：
1. **乳化体系稳定性规律**：HLB值与油水比例的匹配关系决定分层倾向
2. **pH-成分交互规律**：不同成分在酸/碱环境下的稳定性差异
3. **成分配伍矩阵**：30种常见化妆品原料的两两交互关系
4. **加速老化效应**：温度、湿度、光照对稳定性劣化的加速模型

### 1.4 关键挑战

| 挑战 | 应对策略 |
|------|---------|
| 模拟数据与真实数据有偏差 | 在生成逻辑中引入可控噪声，模拟真实测量的不确定性 |
| 成分交互难以量化 | LLM 辅助生成成分交互特征向量 |
| 稳定性标准不统一 | 支持自定义阈值（分层天数、变色ΔE值） |
| 配方格式多样 | 标准化配方模板（INCI名称 + 浓度百分比） |

## 二、数据模型设计

### 2.1 配方记录格式（CSV，由模拟数据集构建器生成）

```
formula_id,emulsifier_type,hlb_value,oil_ratio,water_ratio,ph,viscosity,density,
ing_1_name,ing_1_conc,ing_2_name,ing_2_conc,ing_3_name,ing_3_conc,ing_4_name,ing_4_conc,ing_5_name,ing_5_conc,
interaction_score,temp_c,humidity_pct,light_hours,
separation_days,precipitation_days,color_change_de
```

### 2.2 稳定性标签定义

| 标签 | 含义 | 阈值 |
|------|------|------|
| 分层风险 | 油水分离的天数 | < 30天：高风险；30-90天：中风险；> 90天：低风险 |
| 析出风险 | 出现沉淀的天数 | < 14天：高风险；14-60天：中风险；> 60天：低风险 |
| 变色风险 | 颜色变化ΔE值 | > 3.0：高风险；1.5-3.0：中风险；< 1.5：低风险 |

### 2.3 数据集目录结构

```

│   ├── lab_records.csv          # 实验室原始记录
│   ├── literature_data.csv      # 文献提取数据

├── processed/

│   └── test_data.csv            # 测试集（20%）
└── models/

```

## 三、工具一：配方稳定性模拟数据集构建器

### 3.1 工具概述

**工具 ID**：`cosmetics-stability-dataset-builder`
**工具名称**：配方稳定性模拟数据集构建器
**工具类型**：function
**标签**：`["数据集构建", "模拟数据", "化妆品", "稳定性"]`

### 3.2 功能描述

基于化妆品配方稳定性的已知物理化学规律，生成模拟配方数据集，供后续模型训练和测试演示使用。数据遵循真实配方的统计分布和成分交互规则，确保模拟数据具有教学和演示价值。

生成规则包括：
- 乳化体系（O/W、W/O、W/Si 等）与稳定性的经验关系
- pH 值对析出和变色的非线性影响（酸性/碱性条件下不同成分的稳定性差异）
- 成分之间的已知配伍/不兼容关系（如卡波姆对电解质敏感、某些防腐剂在特定 pH 下失效）
- 加速老化条件（温度、湿度、光照）对稳定性的加速效应

### 3.3 输入参数

| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| `num_samples` | number | 否 | 生成样本数量，默认 500 |
| `output_dir` | path | 否 | 输出目录，默认为 `data/cosmetics_stability/` |
| `test_ratio` | number | 否 | 测试集比例，默认 0.2 |
| `random_seed` | number | 否 | 随机种子，默认 42 |

### 3.4 生成逻辑

1. **基础配方模板**：随机组合 4 种乳化体系类型 × 常见成分池（约 30 种化妆品原料）
2. **成分浓度生成**：在合理范围内随机采样（如保湿剂 1-10%、乳化剂 0.5-5%、防腐剂 0.1-1%），保证配方总和 ≈ 100%
3. **pH 值生成**：按乳化体系类型设定 pH 合理范围（O/W: 4.5-7.5，W/O: 5.0-8.0）
4. **成分交互得分计算**：
   - 加载内置的 30×30 成分交互矩阵
   - 计算配方中所有成分对的兼容性加权平均分
   - 引入噪声模拟真实测量误差
5. **稳定性标签生成**（核心公式）：
   - **分层天数** = f(乳化剂HLB值, 油水比例, 粘度, 成分交互得分) + 噪声
   - **析出天数** = f(pH, 成分交互得分, 温度) + 噪声
   - **变色ΔE** = f(pH偏离最优值, 防腐剂类型, 光照时间, 成分交互得分) + 噪声
6. **环境条件**：随机生成温度（20-50°C）、湿度（30-90%）、光照时间（0-24h）
7. **数据集拆分**：按 `test_ratio` 拆分为训练集和测试集
8. **注册数据集**到 SOTABand 数据空间

### 3.5 内置成分交互规则（部分示例）

| 成分A | 成分B | 交互类型 | 说明 |
|-------|-------|---------|------|
| 卡波姆 | 电解质（NaCl等） | 不兼容 | 导致粘度急剧下降 |
| 苯氧乙醇 | 非离子乳化剂 | 配伍 | 正常使用 |
| 维生素C | 高pH环境 | 不兼容 | 加速氧化变色 |
| EDTA-2Na | 大多数成分 | 协同 | 螯合金属离子，增强稳定性 |
| 有机防晒剂 | 阳离子乳化剂 | 拮抗 | 降低防晒效率 |

## 四、工具二：配方稳定性预测模型训练器

### 4.1 工具概述

**工具 ID**：`cosmetics-stability-model-trainer`
**工具名称**：配方稳定性预测模型训练器
**工具类型**：function
**标签**：`["模型训练", "稳定性预测", "化妆品", "机器学习"]`

### 4.2 功能描述

使用构建好的配方数据集，训练机器学习模型，预测新配方的分层、析出和变色风险。
支持多种模型（Random Forest、XGBoost、LightGBM），自动选择最佳模型并保存。

### 4.3 输入参数

| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| `train_data` | path | 是 | 训练数据 CSV 文件路径 |
| `test_data` | path | 否 | 测试数据 CSV 文件路径 |
| `model_type` | string | 否 | 模型类型：`rf`/`xgb`/`lgb`/`auto`，默认 `auto` |
| `target` | string | 否 | 目标列：`separation_days`/`precipitation_days`/`color_change_de`/`all`，默认 `all` |
| `output_dir` | path | 否 | 模型输出目录，默认 `models/` |

### 4.4 处理流程

1. 读取训练数据和测试数据
2. 特征工程：自动识别数值/分类特征，处理缺失值
3. 根据 `target` 参数选择训练目标（单目标回归或多目标预测）
4. 如果 `model_type=auto`，训练多个模型并比较性能
5. 使用交叉验证评估模型（5-fold）
6. 计算 SHAP 值，输出特征重要性排序
7. 保存最佳模型为 `.pkl` 文件
8. 输出模型评估指标

### 4.5 输出

```json
{
  "status": "success",
  "output_format": "table",
  "message": "模型训练完成，最佳模型：LightGBM，R²=0.89",
  "data": {
    "best_model": "LightGBM",
    "metrics": {
      "separation_mae": 3.2,
      "precipitation_mae": 2.1,
      "color_change_mae": 0.45,
      "overall_r2": 0.89
    },
    "feature_importance": {
      "ph": 0.28,
      "emulsifier_type": 0.22,
      "oil_ratio": 0.18,
      "interaction_score": 0.15,
      "hlb_value": 0.12
    },
    "model_path": "models/stability_model.pkl"
  }
}
```

## 五、工具三：配方稳定性测试应用

### 5.2 功能描述

输入新配方参数，使用训练好的模型预测稳定性风险。输出分层、析出、变色三个维度的风险等级和预警建议。

### 5.3 输入参数

```json
{

  "hlb_value": 12.5,
  "oil_ratio": 0.25,
  "water_ratio": 0.65,
  "ph": 5.8,
  "viscosity": 12000,
  "ingredients": [
    {"name": "甘油", "concentration": 5.0, "function": "保湿剂"},

    {"name": "苯氧乙醇", "concentration": 0.8, "function": "防腐剂"},
    {"name": "鲸蜡醇", "concentration": 3.0, "function": "乳化剂"},
    {"name": "聚二甲基硅氧烷", "concentration": 2.0, "function": "润肤剂"}

    "temp_c": 25,
    "humidity_pct": 60,
    "light_hours": 12
```

### 5.5 处理流程

1. 解析配方 JSON 输入
2. 加载训练好的模型
3. 查询成分交互数据库，计算交互得分
4. 构建特征向量
5. 模型预测（分层天数、析出天数、变色ΔE）
6. 根据阈值判断风险等级
7. 生成预警建议
8. 输出详细预测报告

## 六、实施路线图

### Phase 1：数据基础（工具一）

1. 在 SOTABand 中创建 `cosmetics-stability-dataset-builder` 工具
2. 工具内置 30 种常见化妆品原料及其交互规则矩阵
3. 基于物理化学规律实现模拟数据生成逻辑
4. 生成 500 条模拟配方样本（400 训练 + 100 测试）
5. 自动注册数据集到数据空间

### Phase 2：模型训练（工具二）

1. 在 SOTABand 中创建 `cosmetics-stability-model-trainer` 工具
2. 使用工具编辑器自动生成训练代码
3. 沙箱测试验证模型性能
4. 注册工具到工具空间

### Phase 3：应用测试（工具三）

1. 在 SOTABand 中创建 `cosmetics-stability-predictor` 工具
2. 加载 Phase 2 训练的模型
3. 用真实配方数据进行验证
4. 在对话界面中测试端到端流程：输入配方 → 预测风险 → 预警建议

### Phase 4：迭代优化

1. 收集更多配方数据，更新数据集
2. 重新训练模型，提升预测精度
3. 根据用户反馈优化预警建议模板
