# 专利工具移植环境清单

> 适用场景：把「专利关键词检索 / 专利相关检索 / 专利本地查重」三个工具移植到另一台 SOTABand。
> 前提：整体移植 SOTABand（目录结构保持不变），因此路径依赖天然成立，无需改代码。

---

## 一、三个工具依赖速查

| 工具 | LLM | Playwright | 访问 Google | pypdf/docx |
|------|-----|-----------|-------------|-----------|
| 专利关键词检索（需要VPN） | ❌ | ✅ | ✅ | ❌ |
| 专利相关检索（需要VPN） | ✅ | ✅ | ✅ | ✅ |
| 专利本地查重 | ✅ | ❌ | ❌ | ✅ |

## 二、目标机器要装的东西

### 1. Python 第三方包

```bash
pip install playwright requests pypdf python-docx
```

> 说明：`pypdf` 和 `PyPDF2` 二选一即可，代码里两者都做了兜底；`python-docx` 用于读 docx 文件。

### 2. Playwright 浏览器内核（关键，容易漏）

装完 `playwright` 库之后，**必须再执行一次**：

```bash
playwright install chromium
```

> 只 `pip install playwright` 是不够的，缺内核时检索工具会报「浏览器通道不可用」。
> 若目标机器已装有 Chrome / Edge，代码会尝试自动回退使用，但 headless + 代理行为可能不稳定，建议仍装 chromium。

### 3. LLM 配置（仅「专利相关检索」「专利本地查重」需要）

`config/settings.py` 从环境变量读取，目标机器需要配置以下任一组合：

```bash
# 方式一：通用变量（默认 provider 为 deepseek）
LLM_API_KEY=你的key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-v4-pro

# 方式二：按服务商前缀（如 deepseek / doubao / qwen 等）
DEEPSEEK_API_KEY=你的key
```

> 具体变量名以 `config/settings.py` 中的 `PROVIDER_PRESETS` 和注释为准。
> 未配置时，工具 2、3 会因缺少 api_key 报错。

### 4. 网络与代理（仅「专利关键词检索」「专利相关检索」需要）

- 目标机器必须能访问 Google Patents（`patents.google.com`）。
- 必须开启 **Windows「系统代理」**（不只是 VPN 软件内部开关），工具通过 `winreg` 读取系统代理。
- 注意：代理读取目前是 Windows-only，macOS/Linux 上暂不支持。
