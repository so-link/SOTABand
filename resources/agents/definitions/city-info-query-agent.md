# 城市信息查询 Agent

## 1. 功能概述

接收用户自然语言查询，通过多轮对话理解用户意图、澄清必要参数，并根据意图调用城市天气预报或航班查询工具，最终以自然语言向用户展示工具执行结果。

## 2. 角色定位

- **角色类型**: interactive
- **在系统中的位置**: 位于交互层，作为面向用户的入口 Agent，负责对话管理、意图识别与工具编排
- **协作对象**: 【【城市天气预报】】、【【航班查询工具】】

## 3. 输入规范

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| content | string | 是 | 用户输入的原始文本，用于理解用户意图并提取城市、航班数量等参数 |

## 4. 输出规范

| 事件类型 | 说明 | 数据结构 |
|----------|------|---------|
| content | 文本输出（流式） | `{"text": "..."}` |
| card | 结构化卡片（天气/航班结果摘要） | `{"type": "weather/flight", "title": "...", "data": {...}}` |
| done | 执行结束 | `{"messageId": "..."}` |
| error | 错误信息 | `{"code": "...", "message": "..."}` |

## 5. API 调用

无（本 Agent 不直接调用系统 API，通过工具完成外部数据获取）。

## 6. 工具调用

### 6.1 【【城市天气预报】】

- **调用时机**: 当识别用户意图为查询城市天气，且城市信息已明确后调用
- **输入参数**:

| 参数名 | 来源 | 说明 |
|--------|------|------|
| city | 来自 Agent 输入，经多轮对话澄清后提取 | 城市名称，如“北京”“上海” |
| lang | 固定值为 "zh"，或根据用户偏好调整 | 返回信息语言，默认中文 |

- **输出**:

| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | 执行状态 (success/failed) |
| message | string | 结果说明 |
| data | dict | 天气预报输出数据 |

- **异常处理**: 工具返回 `failed` 时，向用户说明查询失败原因，并引导用户确认城市名后重试。

### 6.2 【【航班查询工具】】

- **调用时机**: 当识别用户意图为查询城市航班，且城市、返回数量等参数已明确后调用
- **输入参数**:

| 参数名 | 来源 | 说明 |
|--------|------|------|
| city | 来自 Agent 输入，经多轮对话澄清后提取 | 要查询的城市名称，支持中文 |
| n | 来自 Agent 输入提取或用户确认 | 最多返回的航班数量，必须为正整数 |

- **输出**:

| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | 执行状态 (success/failed) |
| message | string | 结果说明 |
| data | dict | 航班查询输出数据 |

- **异常处理**: 工具返回 `failed` 时，向用户说明查询失败原因，并引导用户补充或修正参数后重试。

## 7. 执行流程

本 Agent 为交互式多轮对话 Agent，无固定线性流程，由对话管理器动态驱动：接收用户输入 → 意图识别 → 参数澄清 → 调用相应工具 → 汇总结果回复。

## 8. 错误处理

| 异常场景 | 处理方式 |
|----------|---------|
| API 调用失败 | 不适用，本 Agent 不直接调用 API |
| 工具执行失败 | 检查 status=failed，返回工具 message 中的错误信息 |
| 输入参数缺失 | 通过多轮对话引导用户补充城市、航班数量等必要参数 |
| 超时 | 60s 超时，返回提示信息，建议用户稍后重试 |
