# 专利撰写

## 1. 功能概述

本工具基于用户提供的技术方案描述文件（文本类，如 `.txt` / `.md` / `.pdf`），调用系统统一配置的大语言模型（LLM）生成符合中国《专利审查指南》及《专利法实施细则》要求的中文专利说明书初稿。输出为结构完整、术语规范、逻辑严谨的 Markdown 格式专利说明书文件，包含「技术领域」「背景技术」「发明内容」「具体实施方式」四大部分，并自动保存至源文件同目录。

> ✅ 注：LLM 调用由系统封装为 `_llm_chat` 工具函数，自动继承全局 `LLM_PROVIDER` / `LLM_API_KEY` / `LLM_MODEL` 配置，本工具**不自行管理或暴露密钥**。

## 2. 输入规范

| 参数名 | 类型   | 必填 | 默认值 | 说明 |
|--------|--------|------|--------|------|
| path   | string | 是   | 无     | 技术方案描述文件的绝对路径（支持 `.txt`, `.md`, `.pdf`；PDF 将自动提取文本） |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | `success` / `failed` |
| message | string | 执行结果摘要（如“专利说明书已生成并保存至 /xxx/专利说明书_图像压缩_202609301422.md”） |
| output_format | string | `file`（固定） |
| data | dict | 包含生成文件路径信息 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `file` | `{"file_path":"/path/to/专利说明书_{简称}_{timestamp}.md"}` | 提供下载链接按钮 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| PyPDF2 或 pypdf | ≥3.0.0 | PDF 文件文本提取（若输入为 PDF） |
| markdown | ≥3.0.0 | Markdown 内容格式校验与安全渲染（可选） |
| _llm_chat（系统内置工具） | — | 封装 LLM 请求，自动注入配置与上下文模板 |

## 5. 运行机制

### 5.1 执行流程
1. **文件读取与预处理**  
   - 根据 `path` 读取文件；若为 PDF，调用 `pypdf.PdfReader` 提取全部文本页；
   - 清理空白行、冗余换行符，生成纯文本技术方案描述（`tech_desc_text`）。
2. **LLM 提示工程与调用**  
   - 构造结构化 prompt，明确要求输出四部分（技术领域 / 背景技术 / 发明内容 / 具体实施方式），强调术语规范性、法律适配性、非贬低表述、支持性实施例等约束；
   - 调用 `_llm_chat(prompt=..., model=LLM_MODEL, provider=LLM_PROVIDER)` 获取 LLM 响应；
   - 对响应做基础校验（是否含四标题、是否为空、是否含明显幻觉表述）。
3. **格式化与落盘**  
   - 将 LLM 输出按 `## 技术领域` / `## 背景技术` / `## 发明内容` / `## 具体实施方式` 分割并清洗（保留 Markdown 标题层级）；
   - 自动提取技术方案简称（取文件名中首个中文词或英文单词，长度≤8字符，去除特殊符号）；
   - 生成时间戳（`YYYYMMDDHHMM` 格式）；
   - 合成文件名：`专利说明书_{简称}_{timestamp}.md`；
   - 保存至 `os.path.dirname(path)` 目录下。
4. **返回结果**  
   - 返回 `status=success` + `file_path`，或捕获异常返回 `failed` + 错误原因。

### 5.2 错误处理
- `FileNotFoundError` → `message="技术方案文件不存在，请检查路径：{path}"`  
- `UnsupportedFileTypeError`（非 txt/md/pdf）→ `message="仅支持 .txt、.md、.pdf 格式"`  
- `_llm_chat` 调用失败 → `message="大模型服务不可用，请稍后重试"`  
- LLM 输出缺失关键章节 → `message="模型未按要求生成完整结构，请重试或优化原始描述"`  
- 文件写入失败（权限/磁盘满）→ `message="无法保存说明书文件，请检查目标目录权限与空间"`
