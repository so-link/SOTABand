# 论文修改建议

## 1. 功能概述

对给定会议论文 PDF，根据指定会议 `{conf}` 的评审标准，调用系统统一配置的大模型（LLM，跟随全局 `LLM_PROVIDER` / `LLM_API_KEY` / `LLM_MODEL` 配置自动选择服务商，使用工具模板提供的 `_llm_chat` 辅助函数）进行全面评阅并生成详细修改建议。评审覆盖创新性、结构完整性、贡献一致性、公式解释、实验充分性、可读性与可复现性等维度，最终按照会议标准打分并给出判定。评审报告以 Markdown 文件保存至项目目录 `./data/papers/{xxxx}/` 下，并自动将报告目录注册为数据集 `{dataset}`（若不存在则创建）。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| path | string | 是 | - | 待评审的 PDF 论文文件绝对或相对路径 |
| conf | string | 是 | - | 投稿的会议名称（如 ACL、NeurIPS），用于匹配评审标准 |
| dataset | string | 是 | - | 评审结果输出数据集的名称，用于数据集注册与存储 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | 执行结果：`success` / `failed` |
| message | string | 结果说明（如“评审完成并保存至 xxx”） |
| output_format | string | 本次输出格式为 `text` |
| data | dict | 包含 `text` 字段，存放完整的评审意见 Markdown 内容 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text": "完整的评审意见 Markdown 文本"}` | 纯文本渲染，支持 Markdown 格式显示 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| Python | ≥3.8 | 运行环境 |
| (内置) core.llm | - | 系统统一 LLM 客户端（跟随全局 LLM_PROVIDER / LLM_API_KEY / LLM_MODEL） |
| PyPDF2 / pdfplumber | ≥3.0 | PDF 文本提取（需先解析为纯文本再调用 LLM） |

## 5. 运行机制

### 5.1 执行流程
1. **评审论文**：
   - 读取 `{path}` 指定的 PDF 文件并解析为纯文本，使用工具模板提供的 `_llm_chat(messages, ...)` 调用系统统一 LLM 进行评审。
   - 构造系统提示，要求模型使用中文，重点涵盖以下方面：
     (1) 总体创新性评估  
     (2) 结构、形式、实验完整性评估  
     (3) 摘要、简介与章节安排的一致性、衔接连贯性  
     (4) 总体思路章节的技术点与贡献、后续章节的对应  
     (5) 每个公式的目的说明与符号解释  
     (6) 消融实验完整性及核心参数敏感性分析  
     (7) 实验对比 baseline 的先进性、完备性  
     (8) 可读性与可复现性评估  
     (9) 针对上述重点提供详细修改建议和指引  
     (10) 按照 `{conf}` 的评审标准进行评议并最终打分判定。
   - 评审时间戳使用系统当前时间。
2. **保存评审报告**：将模型返回的评审意见记录为 Markdown 文件，保存至项目目录下的子目录 `./data/papers/{xxxx}/`（其中 `{xxxx}` 为根据论文文件名或时间生成的唯一标识），文件命名规则为 `review_{timestamp}.md`。
3. **数据集注册**：
   - 调用系统 API **【获取数据集信息】** 查询数据集 `{dataset}` 是否存在。
   - 若不存在，调用 **【数据集注册API】** 将目录 `./data/papers/{xxxx}/` 注册为数据集 `{dataset}`。
4. 最终返回 `status`、`message` 以及包含完整评审内容的数据体。

### 5.2 错误处理
- **论文文件不存在**：在路径校验阶段即返回错误，提示文件路径无效。
- **LLM 调用异常**（网络、额度不足、超时等）：捕获并返回详细错误信息。
- **文件保存权限不足**：返回错误，提示目标目录不可写。
- **数据集注册失败**：返回错误，提示注册 API 返回的具体原因，但不影响已生成的评审报告本地保存。
