# PDF参考文献真实性验证器

## 1. 功能概述

本工具用于验证 PDF 格式学术论文中参考文献的真实性。通过解析论文的参考文献列表，并对每条引文进行网络搜索获取 URL 和相关网页信息，最终生成一个包含引文信息、是否存在以及论文 URL 的表格，用于辅助判断参考文献的可靠性。

## 2. 输入规范

| 参数名 | 类型   | 必填 | 默认值 | 说明                                  |
|--------|--------|------|--------|---------------------------------------|
| `path` | string | 是   | 无     | PDF 论文文件的本地路径或可访问的 URI |

## 3. 输出规范

### 3.1 标准输出字段
| 字段          | 类型   | 说明                                      |
|---------------|--------|-------------------------------------------|
| status        | string | `success` 或 `failed`                     |
| message       | string | 结果说明或错误描述                         |
| output_format | string | 固定为 `table`                            |
| data          | object | 包含 `columns` 和 `rows` 字段的表格数据   |

### 3.2 可视化输出格式
| output_format | data 格式                                  | 界面渲染方式 |
|---------------|--------------------------------------------|--------------|
| `table`       | `{"columns":["引文信息","是否存在","URL"],"rows":[["论文标题...","是","https://..."],...]}` | 渲染为表格   |

- `columns`：固定为 `["引文信息", "是否存在", "URL"]`。
- `rows`：每个元素为包含三列的列表，分别存储参考文献的格式化文本（如标题、作者、期刊等）、真实性判定（“是”或“否”）、以及找到的论文 URL（若不存在则为空字符串）。

## 4. 依赖环境

| 依赖              | 版本     | 用途                                       |
|-------------------|----------|--------------------------------------------|
| PyMuPDF (fitz)    | >=1.20.0 | PDF 文本提取，用于获取参考文献段落        |
| requests          | >=2.28.0 | 调用 DeepSeek API、访问搜索引擎            |
| beautifulsoup4    | >=4.11.0 | 网页解析，辅助分析搜索结果                    |
| googlesearch-python| >=1.2.3 | Google 搜索接口，查找参考文献的 URL       |

> **注意**：实际生产中可替换为其他搜索服务（如 Bing API、SerpAPI），需根据应用环境调整。

## 5. 运行机制

### 5.1 执行流程

1. **读取 PDF 文件**  
   通过 `PyMuPDF` 加载指定路径的 PDF，提取全文文本。

2. **获取 DeepSeek API KEY**  
   调用系统 API `【获取DeepSeek API KEY】`，获取可用的 API KEY。

3. **解析参考文献**  
   将提取到的文本（或其中包含参考文献的段落）通过 DeepSeek v4 pro 大模型进行语义分析，利用 ChatGPT 的消息格式（使用 API KEY 鉴权），输出结构化的参考文献列表（每项包含标题、作者等信息）。

4. **逐条验证真实性**  
   对每个参考文献：
   - 使用搜索引擎（如 Bing）以 `论文标题 + 作者` 为查询词搜索前 5 条结果；
   - 抓取搜索结果页，解析标题和摘要，结合 URL 判断是否存在该论文的官方页面或可用链接；
   - 综合判断该文献是否存在（“是”或“否”），并记录第一条最相关的 URL（若无则为空）。

5. **生成结果表格**  
   将所有验证结果组装为二维列表，构造标准输出对象返回。

### 5.2 错误处理

- **文件不存在/无法读取** → 返回 `status: failed`，`message` 说明具体错误。
- **【获取DeepSeek API KEY】调用失败** → 返回失败状态并提示无法获取密钥。
- **大模型解析参考文献失败**（如无参考文献段落） → 返回失败，指明解析异常。
- **网络搜索异常**（如超时、反爬限制） → 该条参考文献标记为“无法验证”，URL 为空，并在整体 message 中附加警告信息。
- **参数无效**（路径为空） → 返回验证错误。
