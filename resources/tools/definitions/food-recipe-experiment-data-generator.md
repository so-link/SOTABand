# 食品配方实验数据生成器

## 1. 功能概述

根据指定的数据条目数，模拟生成食品配方实验的表格数据，保存为 CSV 文件到带时间戳的子目录中，并通过【数据集注册API】将该目录注册为数据集。最终以表格形式返回生成的数据预览。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| n | integer | 是 | - | 生成的数据条目数（行数） |
| output_dataset | string | 是 | - | 数据集注册名称 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | table |
| data | dict | 输出数据（columns+rows） |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `table` | `{"columns":["配方ID","成分A(%)","成分B(%)","温度(℃)","时间(min)","感官评分"], "rows":[["R001","12.5","35.2","180","45","7.8"], ...]}` | 渲染表格 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| pandas | >=1.3.0 | 生成表格数据并保存 CSV |
| numpy | >=1.21.0 | 生成随机数据 |
| os | 标准库 | 文件路径操作 |
| datetime | 标准库 | 生成时间戳 |
| sys | 标准库 | 系统调用，注册API预留 |

## 5. 运行机制

### 5.1 执行流程
1. 读取输入参数 `n` 和 `output_dataset`
2. 生成时间戳 `{xxxx}`，创建目标目录 `'./data/download/{xxxx}/'`
3. 使用 `numpy` 和 `pandas` 模拟生成包含配方ID、成分A(%)、成分B(%)、温度(℃)、时间(min)、感官评分等字段的 `n` 行实验数据
4. 将数据保存为 `experiment_data.csv` 到该目录下
5. 调用【数据集注册API】，将目录路径注册为数据集名称 `{output_dataset}`
6. 构建表格型输出数据并返回

### 5.2 错误处理
- 参数 `n` 非正数或非整数 → 返回错误信息“生成条目数必须为正整数”
- 目录创建失败 → 返回错误信息“无法创建目标目录”
- CSV 写入失败 → 返回错误信息“保存 CSV 文件失败”
- 数据集注册 API 调用失败 → 捕获异常并返回详细错误信息
