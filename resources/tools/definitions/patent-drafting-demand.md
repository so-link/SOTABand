工具名：专利撰写

输入： 技术方案描述文件路径{path}

过程：
1. 调用系统统一配置的大模型（LLM）辅助专利文书撰写（LLM 调用由系统统一处理，使用工具模板提供的 _llm_chat 辅助函数，跟随全局 LLM_PROVIDER / LLM_API_KEY / LLM_MODEL 配置，无需自行获取 API KEY；需将路径{path}下对应的技术方案描述文件完整传入 LLM）。撰写要求用中文，文书内容需包含但不限于如下部分：
（1）技术领域：根据文件内容，明确本发明所属或直接应用的技术领域，表述应规范、准确，避免过于宽泛或过于狭窄。
（2）背景技术：梳理与本发明相关的现有技术状况，客观描述现有技术中存在的问题或不足，为引出本发明的技术方案做铺垫，避免贬低他人已有成果。
（3）发明内容：清晰陈述本发明要解决的技术问题、采用的技术方案以及相对于现有技术的有益效果。技术方案应完整、清楚，能够解决所提出的技术问题；有益效果应客观、具体，避免夸大宣传。
（4）具体实施方式：针对技术方案，给出至少一个具体的实施方式或实施例，详细描述如何实现本发明，包括必要的步骤、参数、条件、材料等，使本领域技术人员能够据此实现。如技术方案涉及装置或系统，应说明各组成部分及其连接关系或工作过程。
要求各部分的表述应符合专利申请文件的格式要求，使用规范的法律和技术术语，避免口语化表达；发明内容部分应与权利要求书的核心技术特征保持一致，具体实施方式应对发明内容形成充分支持。

2. 将上述生成的专利文书各部分内容，按照专利申请文件的规范格式整合为一篇完整的专利说明书，保存为md文件格式，保存在和技术方案描述文件同一个目录下，文件命名格式为 专利说明书_{技术方案简称}_{时间戳}.md。

输出：
专利说明书的内容（包含技术领域、背景技术、发明内容、具体实施方式）。
