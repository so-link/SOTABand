# 函数图像绘制器

## 1. 功能概述
本工具接收一个一元数学函数表达式（如 `y = sin(x) + 2*x`），自动解析表达式、计算函数值并绘制出 y 关于 x 的二维曲线图像，最终以图片形式返回结果。

## 2. 输入规范

| 参数名      | 类型    | 必填 | 默认值            | 说明 |
|-------------|---------|------|-------------------|------|
| equation    | string  | 是   | -                 | 一元函数表达式，要求以 `y = f(x)` 的格式给出，支持四则运算、幂运算、常见初等函数（sin, cos, tan, exp, log, sqrt 等） |
| x_range     | list    | 否   | [-10, 10]         | 自变量 x 的取值区间，格式为 `[min, max]`（闭区间） |
| num_points  | int     | 否   | 1000              | 在定义域内生成的采样点数量，决定曲线平滑度 |
| image_size | list     | 否   | [800, 600]        | 输出图像的尺寸（宽度, 高度），单位像素 |
| title       | string  | 否   | "函数图像"        | 图表标题 |
| x_label     | string  | 否   | "x"               | x 轴标签 |
| y_label     | string  | 否   | "y"               | y 轴标签 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段          | 类型   | 说明 |
|---------------|--------|------|
| status        | string | `success` 表示绘制成功，`failed` 表示失败 |
| message       | string | 结果说明，成功时返回空或确认信息，失败时包含错误原因 |
| output_format | string | 固定为 `image` |
| data          | dict   | 输出数据，包含图片路径 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `image`       | `{"image_path":"/path/to/file.png"}` | 直接绘制图片 |

**data 详细说明（成功时）：**
```json
{
  "image_path": "生成图像的本地绝对路径"
}
```

## 4. 依赖环境

| 依赖       | 版本    | 用途 |
|------------|---------|------|
| numpy      | >=1.21  | 数值计算、生成 x 采样点 |
| matplotlib | >=3.5   | 绘图与图像保存 |
| sympy      | >=1.9   | 解析数学表达式，转换为可计算的函数 |
| Pillow     | >=9.0   | 图像处理辅助（可选） |

## 5. 运行机制

### 5.1 执行流程
1. **解析表达式**：使用 `sympy` 将输入字符串 `equation` 解析为符号表达式，并提取出可数值计算的 `lambdify` 函数。
2. **参数校验**：检查 `x_range` 是否有效（左端点 < 右端点），`num_points` 是否为正整数等。
3. **生成数据点**：在区间 `[x_range[0], x_range[1]]` 上生成 `num_points` 个等间距的 `x` 值，通过解析后的函数计算对应的 `y` 值。
4. **绘制图像**：利用 `matplotlib` 创建图表，设置标题、轴标签、图例等，绘制曲线并应用默认美观样式。
5. **保存图片**：将图像保存为 PNG 格式到系统临时目录，返回图片路径。
6. **清理与返回**：关闭绘图对象释放内存，返回标准输出结构。

### 5.2 错误处理
- **表达式格式错误**（如缺少 `y=`、等号数量异常）→ 返回 `status: "failed"`，`message` 中提示正确的输入格式。
- **表达式解析失败**（如包含未定义的函数、语法错误）→ 返回详细解析错误信息。
- **参数无效**（如 x_range 为 [10, -10]，num_points 为非正数）→ 返回参数验证错误及具体修正建议。
- **绘图/保存异常**（如磁盘空间不足、权限问题）→ 捕获异常并返回系统级错误信息。
