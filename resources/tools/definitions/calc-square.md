# 整数平方计算器

## 1. 功能概述

接收一个整数 `n`，计算并返回 `n` 的平方值。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| n      | int  | 是   | 无     | 待计算平方的整数 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | `success` 或 `failed` |
| message | string | 结果描述，如 "平方计算完成" |
| output_format | string | 固定为 `"text"` |
| data | object | 包含 `input` 和 `square` 字段 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"input":n, "square":n*n}` | 纯文本显示，例如：`{n} 的平方是 {square}` |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| python | >=3.6 | 运行环境 |

## 5. 运行机制

### 5.1 执行流程
1. 读取输入参数 `n`
2. 校验 `n` 是否为整数类型
3. 计算 `square = n * n`
4. 构造返回结果

### 5.2 错误处理
- 如果 `n` 不是整数类型 → 返回 `status: "failed"`，`message` 提示需要整数
- 如果 `n` 数值过大导致溢出（Python 自动处理大整数，一般无此问题） → 捕获异常返回错误信息
