# 专利检索与翻译工具

## 1. 功能概述

根据用户输入的技术需求 `req`、期望专利数量 `n`、发表年限 `year` 及目标数据集名称 `dataset`，自动完成以下任务：
1. 调用专利检索与注册工具获取相关专利信息；
2. 获取 DeepSeek API 密钥；
3. 获取指定数据集的本地目录路径；
4. 调用 DeepSeek V4 Pro 大模型，将数据集目录下所有 Markdown 文件内容翻译为中文并原地替换。

最终输出数据集所在路径 `data_path`。

## 2. 输入规范

| 参数名  | 类型   | 必填 | 默认值 | 说明                           |
|---------|--------|------|--------|--------------------------------|
| req     | string | 是   | -      | 用户需求描述，用于专利检索     |
| n       | int    | 是   | -      | 需要检索并注册的专利数量       |
| year    | int    | 是   | -      | 专利发表年限                   |
| dataset | string | 是   | -      | 数据集名称，用于定位存储目录   |

## 3. 输出规范

### 3.1 标准输出字段
| 字段          | 类型   | 说明                         |
|---------------|--------|------------------------------|
| status        | string | success / failed             |
| message       | string | 结果说明，如“翻译完成”等     |
| output_format | string | text                         |
| data          | dict   | `{"data_path": "翻译后的数据集路径"}` |

### 3.2 可视化输出格式
| output_format | data 格式                             | 界面渲染方式                     |
|---------------|---------------------------------------|----------------------------------|
| `text`        | `{"text":"翻译成功，文件路径: /data"}` | 纯文本显示 `text` 字段内容       |

## 4. 依赖环境

| 依赖      | 版本   | 用途                       |
|-----------|--------|----------------------------|
| python    | ≥3.9   | 运行环境                   |
| requests  | ≥2.28  | 调用网络 API（如需）       |
| openai    | ≥1.0.0 | 对接 DeepSeek 大模型 API   |
| (内置) os | -      | 文件遍历与路径处理         |

## 5. 运行机制

### 5.1 执行流程
1. 接收参数 `req`, `n`, `year`, `dataset` 并校验类型与合法性。
2. 调用 **【【Lens专利检索与注册工具】】**，传入参数：用户需求 `req`，数量 `n`，发表年限 `year`，数据集名称 `dataset`，完成专利检索与注册。
3. 调用 **【获取DeepSeek API KEY】** 获取可用的 API 密钥 `api_key`。
4. 调用 **【获取数据集信息】** 获取数据集 `dataset` 的本地目录路径 `data_path`。
5. 遍历 `data_path` 目录下所有 `.md` 文件，使用 `api_key` 调用 DeepSeek V4 Pro 大模型进行全文翻译（目标语言：中文），并将翻译后的内容覆盖写回原文件。
6. 返回包含 `data_path` 的成功信息；若任何步骤异常，返回失败状态及错误详情。

### 5.2 错误处理
- 参数类型或范围无效（如 `n` ≤ 0、`year` 非四位数）→ 返回 `status: failed` 并提示验证错误。
- 工具调用【【Lens专利检索与注册工具】】失败 → 捕获异常，返回详细错误信息。
- 【获取DeepSeek API KEY】失败或返回空 → 返回“无法获取 API 密钥”的错误。
- 【获取数据集信息】失败或 `data_path` 不存在 → 返回“数据集路径无效”。
- 翻译过程中 API 调用超时或内容返回异常 → 记录错误文件并跳过，最后汇总失败文件列表，整体状态标记为 `failed`。
