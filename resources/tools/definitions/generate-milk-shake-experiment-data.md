# 奶昔配方实验数据生成与注册

## 1. 功能概述

本工具用于模拟生成奶昔配方实验的多变量表格数据，支持自定义样本数量。生成的数据保存为 CSV 文件到带时间戳的子目录中，并通过【数据集注册API】将该目录注册为指定名称的数据集，便于后续分析或模型训练。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| n | int | 是 | 无 | 生成的样本数量（数据条目） |
| output_dataset | string | 是 | 无 | 注册数据集的名称 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | table |
| data | dict | 表格数据 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `table` | `{"columns": [...], "rows": [[...], ...]}` | 渲染表格 |

具体输出内容为生成的奶昔配方实验数据表，包含以下列：
- 实验ID
- 分离乳清蛋白(g)
- 麦芽糊精(g)
- 植物油(g)
- 大豆卵磷脂(g)
- 均质压力(MPa)
- 杀菌温度(℃)
- 存放时间(天)
- 沉淀率(%)
- 整体喜好度（0~10）

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| pandas | >=1.5.0 | 数据处理与CSV读写 |
| numpy | >=1.23.0 | 随机数生成 |
| os | 内置 | 目录与路径操作 |
| time | 内置 | 时间戳生成 |
| requests | >=2.28.0 | 调用【数据集注册API】 |

## 5. 运行机制

### 5.1 执行流程
1. 读取输入参数 n 和 output_dataset。
2. 校验参数：n 必须为正整数，output_dataset 不能为空。
3. 生成当前时间戳 `xxxx`，创建目录 `./data/download/{xxxx}/`。
4. 使用 numpy 或随机函数模拟生成 n 行实验数据，每行包含上述所有字段，数值范围符合实际配方与工艺经验。
5. 将数据组织为 DataFrame，保存为 CSV 文件到上述目录中（文件名可自动生成，如 `experiment_data.csv`）。
6. 调用【数据集注册API】，将目录 `./data/download/{xxxx}/` 注册为数据集 `{output_dataset}`。
7. 将生成的表格数据以 `table` 格式返回（包含列名和行数据）。

### 5.2 错误处理
- 参数 n 非正整数 → 返回 `status: failed`，`message: "参数n必须为正整数"`。
- output_dataset 为空 → 返回 `status: failed`，`message: "数据集名称不能为空"`。
- 目录创建失败 → 返回详细错误信息。
- 文件写入失败 → 返回详细错误信息。
- 注册API调用失败 → 返回 `status: failed`，`message: "数据集注册失败: {错误详情}"`。
