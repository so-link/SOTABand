# 问候测试

## 1. 功能概述

接收用户的问候指令，返回该指令加上 "hello" 后缀的文本。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| command | string | 是 | - | 用户的问候指令 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | text |
| data | dict | 输出数据 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"{command}, hello"}` | 纯文本 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| 无 | — | 纯内置函数，无外部依赖 |

## 5. 运行机制

### 5.1 执行流程
1. 接收输入参数 `command`
2. 校验 `command` 是否为非空字符串
3. 拼接字符串：`"{command}, hello"`
4. 返回结果

### 5.2 错误处理
- `command` 为空 → 返回错误信息，提示指令不能为空
- 参数类型不正确 → 返回验证错误
