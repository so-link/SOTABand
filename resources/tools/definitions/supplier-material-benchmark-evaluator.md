# 供应商原材料基准吻合度评估工具

## 1. 功能概述

根据评估基准文件，提取五大核心基准维度（原料来源基准、生产工艺流程基准、关键质量指标阈值、动物源性管控基准、食品专项安全基准），生成基准比对字段及要求，并保存为 CSV 文件。随后对指定目录下各供应商的原材料资料 PDF 文件进行解析，调用 DeepSeek V4 Pro 大模型评估其与基准的吻合程度（1~100 分），最终生成包含所有供应商评分列表及详细分析报告的 Markdown 文档，并将完整文件内容作为输出返回。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| filepath | string | 是 | 无 | 评估基准文件的路径，用于解析生成基准比对字段 |
| dirpath | string | 是 | 无 | 目录路径，用于读取供应商原材料资料 PDF，并保存生成的 CSV 与 MD 报告 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | text / image / table / file |
| data | dict/list | 输出数据 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"完整的Markdown报告内容，包含供应商评分列表和详细分析报告"}` | 纯文本 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| requests | >=2.31 | 调用 DeepSeek API 及 HTTP 请求 |
| openai | >=1.0 | 兼容 DeepSeek API 的 SDK 调用 |
| pdfplumber | >=0.11 | 解析供应商原材料 PDF 资料 |
| pandas | >=1.5 | 读取/写入基准比对字段 CSV，处理表格数据 |

## 5. 运行机制

### 5.1 执行流程
1. 调用系统API【获取DeepSeek API KEY】获取 DeepSeek 大模型 API Key。
2. 读取输入基准文件 `filepath`，调用 DeepSeek V4 Pro 大模型解析并提取五大核心基准维度：原料来源基准、生产工艺流程基准、关键质量指标阈值（纯度/含量/水分/重金属/塑化剂等）、动物源性管控基准、食品专项安全基准（农残、塑化剂合规要求），生成基准比对字段及要求，保存为 CSV 文件至目录 `dirpath`。
3. 扫描目录 `dirpath` 下所有供应商原材料资料 PDF 文件。
4. 对每个 PDF 文件，解析文本并提取各基准比对字段的取值，调用 DeepSeek V4 Pro 大模型评估其与基准的吻合程度（1~100 分），生成单个供应商的分析报告摘要。
5. 汇总所有供应商评估结果，生成 Markdown 文档：文档开头为各供应商评估分数列表，后续为详细分析报告，按五大核心基准维度对照分析，注意排版和段落逻辑。
6. 将 MD 报告保存至目录 `dirpath`，并将完整文件内容作为 `data.text` 返回。

### 5.2 错误处理
- 基准文件不存在 → 返回错误信息 `filepath 不存在`，状态设为 failed
- 目录路径不存在或无权限 → 返回错误信息，状态设为 failed
- 目录下无供应商 PDF 文件 → 返回错误信息，状态设为 failed
- 基准文件解析失败或未提取到有效基准字段 → 返回错误信息，状态设为 failed
- PDF 解析失败或文本提取为空 → 记录该供应商解析失败，跳过并继续处理其他 PDF，最终报告中标注异常
- DeepSeek API 调用失败或返回异常 → 返回详细错误信息，状态设为 failed
- 保存 CSV 或 MD 文件失败 → 返回错误信息，状态设为 failed
