# ArXiv论文批量下载工具

## 1. 功能概述

根据用户提供的检索需求 `{req}`、下载数量 `{n}` 和起始发表年限 `{year}`，从arXiv检索符合条件的最新论文，下载PDF文件并保存到带时间戳的本地目录中。同时生成包含论文基本信息的CSV文件，最后通过【数据集注册API】将整个目录注册为指定数据集 `{dataset}`。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| req | string | 是 | - | 检索关键词，如 "machine learning" |
| n | int | 是 | - | 需要下载的论文数量 |
| year | int | 是 | - | 起始发表年份（包含当年） |
| dataset | string | 是 | - | 注册数据集时使用的名称 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | file |
| data | dict | 输出数据 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `file` | `{"csv_path":"...", "pdf_dir":"...", "count": N}` | 下载链接 |

data 字典包含以下键：
- `csv_path`: 生成的论文信息CSV文件路径
- `pdf_dir`: 存放PDF文件的目录路径
- `count`: 实际成功下载的论文数量
- `dataset_name`: 注册的数据集名称

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| arxiv | >=2.0.0 | arXiv API 检索与信息获取 |
| requests | >=2.28.0 | 下载论文PDF |
| csv | 内置 | 生成论文信息表 |
| os | 内置 | 文件目录操作 |
| datetime | 内置 | 生成时间戳目录名 |

## 5. 运行机制

### 5.1 执行流程
1. 生成当前时间戳 `{xxxx}`，创建下载目录 `./data/download/{xxxx}/`，并将其设为 `{data_path}`。
2. 调用 `arxiv` 库，根据 `{req}` 检索发表时间在 `{year}` 年及以后的论文，按照发布日期降序排列，取前 `{n}` 篇。
3. 遍历检索结果，下载每篇论文的PDF文件，以论文ID（如 `2101.12345`）命名，保存到 `{data_path}`。
4. 将所有论文的基本信息（标题、作者、arXiv ID、发表年份、链接）整理为CSV文件，保存到 `{data_path}/papers_info.csv`。
5. 构建 `{data_path}` 的目录信息，通过【数据集注册API】将目录注册为 `{dataset}` 数据集。
6. 返回包含路径和数量的结果。

### 5.2 错误处理
- arXiv API 无结果或无符合年份条件的论文 → 返回错误信息并退出。
- 论文缺少PDF链接 → 记录警告日志，继续处理下一篇。
- 单篇下载失败 → 记录错误，不影响其他论文下载，最终返回部分成功信息。
- 目录创建失败 → 返回系统错误信息。
- 数据集注册API调用失败 → 返回API返回的错误信息。
