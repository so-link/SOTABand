# ArXiv论文批量下载器

## 1. 功能概述

根据用户提供的研究需求关键词、论文数量和发表年份限制，自动从 ArXiv 检索相关论文，下载 PDF 全文，提取基本信息并整理为 CSV 表格，最后通过【数据集注册API】将下载目录注册为指定数据集。所有文件存储在以时间戳命名的唯一子目录下。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| req | string | 是 | - | 论文检索关键词或需求描述 |
| n | integer | 是 | - | 需要下载的论文数量（按相关度排序） |
| year | integer | 是 | - | 发表年份限制，检索该年及以后发表的论文 |
| dataset | string | 是 | - | 目标数据集名称，用于【数据集注册API】注册 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明，如“已成功下载并注册数据集” |
| output_format | string | text |
| data | dict | 包含 `directory`（下载目录路径）、`csv_path`（CSV文件路径）、`dataset_name`（注册后的数据集名称） |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"结果描述和路径信息"}` | 纯文本 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| arxiv | >=2.1.0 | 检索和下载 ArXiv 论文 |
| pandas | >=2.0.0 | 生成和管理论文信息 CSV |
| requests | >=2.31.0 | HTTP 请求支持 |
| os, time, datetime | 内置 | 文件路径和目录操作，时间戳生成 |

## 5. 运行机制

### 5.1 执行流程
1. 生成当前时间戳 `{xxxx}`，创建目录 `./data/download/{xxxx}/`，并将 data_path 设置为该目录。
2. 使用 `arxiv` 库构建查询：关键词为 `{req}`，过滤条件为 `year >= {year}`，按相关度排序，取前 `{n}` 条结果。
3. 遍历检索结果，逐一下载论文 PDF 至 `data_path`，文件名使用论文 ID 或标题清理后的字符串。
4. 提取每篇论文的基本信息（标题、作者、年份、摘要、链接等），构建 DataFrame 并保存为 `papers_info.csv` 至 `data_path`。
5. 调用【数据集注册API】，将目录 `data_path` 注册为数据集 `{dataset}`。
6. 返回执行状态、目录路径、CSV 路径和数据集名称。

### 5.2 错误处理
- 目录创建失败 → 返回错误信息并终止。
- ArXiv API 无结果或网络异常 → 返回搜索失败原因，可尝试重试或提示用户。
- 论文下载失败（如链接无效）→ 记录错误信息，跳过该论文继续下载，最终在 CSV 中标注下载状态。
- CSV 写入失败 → 返回文件写入错误。
- 数据集注册失败 → 返回 API 错误详情，提醒用户目录已下载但注册未成功。
