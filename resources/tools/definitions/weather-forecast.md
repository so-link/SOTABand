# 天气预报

## 1. 功能概述

根据用户输入的城市位置和查询天数，获取该城市当天及未来 n 天的天气信息，包括降雨量、风速、天气预警、台风预警等数据，并以结构化表格形式呈现。工具底层调用无需 API Key 的公共天气 API（如 Open-Meteo、wttr.in 等），确保开箱即用。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| city | string | 是 | - | 城市名称（中文或英文，需支持中文转拼音或用经纬度查询）|
| days | integer | 否 | 3 | 未来查询天数，范围 1~16，默认 3 天 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | table（默认）|
| data | object | 输出数据，格式见下表 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `table` | `{"columns":["日期","天气","最高温(℃)","最低温(℃)","降雨量(mm)","风速(km/h)","预警"], "rows":[["2026-08-01","晴",35,28,0,10,"无"],...]}` | 渲染表格 |

若发生错误（如城市不存在），`status` 为 `failed`，`output_format` 为 `text`，`data` 包含错误文本。

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| requests | >=2.25 | HTTP 请求调用天气 API |
| geopy | >=2.0 (可选) | 将城市名称转换为经纬度（如 API 需要经纬度） |
| pinyin | >=0.4 (可选) | 中文城市名转拼音用于 API 请求 |

若使用 wttr.in，只需 `requests` 即可。建议优先采用 wttr.in 的 JSON 接口，无需地理编码，直接接收城市名。

## 5. 运行机制

### 5.1 执行流程
1. 接收 `city` 和 `days` 参数
2. 校验参数：`days` 若未提供则设为 3，且限制在 1~16 范围内
3. 构造 API 请求 URL（例如 `https://wttr.in/{city}?format=j1&days={days}`）
4. 发送 HTTP GET 请求获取 JSON 数据
5. 解析天气数据，提取每日的天气描述、最高/最低温度、降雨量、风速，并检查天气预警字段（若有）
6. 整理为表格格式返回

### 5.2 错误处理
- 网络请求失败 → 返回 `{status:failed, message:"网络连接异常，请检查网络或稍后重试", output_format:"text", data:{"text":"网络错误"}}`
- API 返回缺失或无效数据 → 返回解析错误提示
- 城市名无效或 API 无此城市数据 → 返回 `{status:failed, message:"未查询到该城市的天气数据", output_format:"text", data:{"text":"城市不存在"}}`
- 参数 `days` 超出范围 → 返回验证错误，提示有效范围
