工具名：论文修改建议
输入：pdf论文文件路径{path}，投稿的会议名称{conf}，评审结果输出数据集{dataset}
过程：
  1.调用系统统一配置的大模型（LLM）对论文进行评审（LLM 调用由系统统一处理，使用工具模板提供的 _llm_chat 辅助函数，跟随全局 LLM_PROVIDER / LLM_API_KEY / LLM_MODEL 配置，无需自行获取 API KEY；需先解析 PDF 为纯文本再传给 LLM），并给出详细修改建议， 评审要求用中文， 评审包含但不限于如下关注方面：
（1）从总体的创新性方面进行评估
（2）从论文的结构，形式，实验完整性方面评估
（3）论文的最主要的贡献在摘要，简介以及论文章节安排上，是否一致、衔接是否连贯。摘要的内容是否在简介部分有比好的呼应。
（4）有没有一个章节介绍总体思路，总体思路中陈述的技术点，是否和摘要以及简介中的贡献度相一致，总体思路中的内容是否和后面章节对应
（5）每个公式是否讲清楚了公式的目的，公式中的每个符号是否解释清楚
（6）实验环节是否包含完整的消融实验，核心参数是否有敏感性分析
（7）实验是否充分，对比的baseline方法是否先进和完备。
（8）论文总体可读性如何，可复现性如何
  (9) 要求针对上面评估重点，给出详细的批改建议和指引，供作者参考。
（10）按{conf}的评审标准对论文进行评议和最终的打分判定。

注：评审的时间为系统当前时间。

  3. 把上述评审意见记录为一篇评审报告，保存为md文件格式，保存在项目目录的子目录中’./data/papers/{xxxx}/‘ 
   4. 调用【获取数据集信息】获取数据集{dataset}信息，判断该数据集是否存在，如果该数据集不存在，则通过【数据集注册API】将目录’./data/papers/{xxxx}/‘ 注册为数据集{dataset}。

输出：
       评审意见的内容。
