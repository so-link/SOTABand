# 论文摘要

## 1. 功能概述
根据输入的数据集名称和摘要长度限制，自动获取该数据集下的所有 PDF 文件，提取文本内容，并调用 DeepSeek V4 Pro 大模型为每篇论文生成指定字数的中文摘要，最终将所有摘要合并为一个整体输出。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| dataset | string | 是 | - | 数据集名称 |
| n | integer | 是 | - | 单篇论文摘要的字数上限 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | text |
| data | dict | `{"text": "合并后的中文摘要全文"}` |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"..."}` | 纯文本展示 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| openai | ≥1.0.0 | 调用 DeepSeek API（兼容 OpenAI SDK） |
| pypdf | ≥3.0.0 | 读取与解析 PDF 文件 |
| python | ≥3.10 | 运行环境 |

## 5. 运行机制

### 5.1 执行流程
1. 通过【获取数据集信息】获取数据集 `{dataset}` 的目录路径 `{data_path}`。
2. 通过【获取DeepSeek API KEY】获取 deepseek 大模型的 API_KEY。
3. 扫描 `{data_path}` 下所有 `.pdf` 文件，对每个文件：
   - 使用 `pypdf` 提取全文文本。
   - 构造请求消息，调用 DeepSeek V4 Pro 大模型，要求生成一段不超过 `{n}` 个字的中文摘要。
4. 将所有摘要按原文顺序拼接成一段完整文本。
5. 返回合并后的摘要文本。

### 5.2 错误处理
- **数据集不存在**：`{data_path}` 无法访问或为空 → 返回 `status: failed`，`message` 说明具体原因。
- **目录无 PDF 文件**：扫描到零个合法文件 → 返回提示信息。
- **PDF 解析失败**：某文件无法读取文本 → 记录警告，跳过该文件或返回局部错误。
- **API 调用异常**：网络问题、API KEY 无效或大模型返回异常 → 捕获异常，返回详细错误信息，保证流程不崩溃。
