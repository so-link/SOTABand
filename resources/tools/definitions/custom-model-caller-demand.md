需求：工具可使用自己的 LLM 配置

当前所有工具共用项目 .env 里的全局模型配置（deepseek-v4-flash，纯文本模型）。
某些任务需要多模态（看图）、长上下文或特定厂商的模型时，只能去改全局
.env —— 这会影响其他所有工具。

希望有一个工具，允许在单次调用时临时指定模型配置：

- 服务商（provider）与模型名（model），服务商端点自动解析，无需知道 base_url
- 该服务商的 API Key
- 可选 base_url（仅当服务商不在已知目录时）
- 可选 image_path：需要看图时以多模态方式发送
- max_tokens：推理模型建议 >= 1500

要求：
1. 与全局配置完全隔离，不影响其他工具，其他工具仍用 .env 配置
2. API Key 只在本次调用的内存中使用，不写入配置文件或日志，返回值一律脱敏
3. 失败时给出明确原因（如服务商无法识别时列出全部已知服务商）
4. 异常信息统一脱敏，避免密钥随报错外泄
