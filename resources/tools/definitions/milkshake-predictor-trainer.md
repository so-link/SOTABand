# 奶昔预测模型训练器

## 1. 功能概述

从指定 CSV 文件加载数据，根据用户选择的回归模型类型和测试集比例划分训练集与测试集，训练回归模型（使用除第一列外的所有列作为特征，预测最后一列的目标值），保存模型文件，并调用【模型注册API】将模型注册为名称“奶昔预测模型{时间戳}”的模型。最后返回模型文件路径、训练误差及训练准确率。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| path | string | 是 | - | CSV 数据文件路径，第一列为标识列（不使用），其余列作为特征，最后一列为目标值 |
| model_type | string | 是 | - | 回归器类型，如“random_forest”、“xgboost”、“linear”等，内部将映射至对应的回归模型 |
| r | float | 是 | - | 测试集占比，取值范围 (0,1)，训练集占比 = 1 - r |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | text |
| data | dict | 输出数据 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"模型路径: /path/to/model.pkl, 训练误差: 0.052, 训练准确率: 0.948"}` | 显示纯文本信息 |

*当 status 为 success 时，data 中包含以下字段：*

- `text` : (string) 综合输出文本
- `model_path` : (string) 训练好的模型文件路径
- `train_error` : (float) 训练集上的误差（如 RMSE）
- `train_accuracy` : (float) 训练集上的 R² 决定系数

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| pandas | ≥1.5.0 | CSV 数据读取与处理 |
| scikit-learn | ≥1.3.0 | 数据划分、线性回归、随机森林、评估指标 |
| xgboost | ≥2.0.0 | XGBoost 回归器（若选用） |
| joblib | ≥1.3.0 | 模型文件保存与加载 |

## 5. 运行机制

### 5.1 执行流程
1. 使用 `pandas.read_csv` 加载 `path` 指定的 CSV 文件。
2. 校验参数：`r` 是否在 (0,1) 区间、`model_type` 是否支持、文件是否有效。
3. 划分特征和目标：第一列保留但不参与训练，其余列作为特征 X，最后一列作为目标 y。
4. 使用 `train_test_split` 按 `(1-r):r` 比例划分训练集与测试集。
5. 根据 `model_type` 选择回归模型（如 `RandomForestRegressor`、`XGBRegressor`、`LinearRegression` 等）并进行训练。
6. 计算训练集上的性能：误差（如 RMSE）和准确率（R²）。
7. 使用 `joblib.dump` 保存训练好的模型到临时路径（文件名如 `model_{timestamp}.pkl`），获得 `model` 路径。
8. 调用【模型注册API】注册模型：
   - 模型路径：`model`
   - 模型名称：`奶昔预测模型{当前时间戳}`（例如 `奶昔预测模型20260805123045`）
9. 构建输出文本，包含模型路径、训练误差和准确率，返回统一结构。

### 5.2 错误处理
- 文件不存在或格式错误 → 返回 `status: failed`，`message` 包含具体错误信息。
- 参数 `r` 不在 (0,1) 或 `model_type` 不支持 → 返回参数验证错误。
- 数据中特征数不足、缺失值等异常 → 捕获异常并返回详细错误描述。
- 注册API调用失败 → 记录日志，仍可返回模型训练结果（可注明注册失败），或直接标记为失败。
