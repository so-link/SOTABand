# 论文摘要工具

## 1. 功能概述

针对指定数据集中的所有PDF论文，自动提取文本内容，利用DeepSeek v4 Pro大模型为每篇论文生成不超过{n}字的分析报告，并聚合成一份结构化的Markdown汇总文档，存放于数据集目录下。报告内容涵盖标题、作者、总体内容、主要贡献、科研价值、实验过程与结果等方面。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| dataset | string | 是 | - | 数据集名称，用于通过【获取数据集信息】定位目录 |
| n | integer | 是 | - | 每篇论文分析报告的最大字数（汉字） |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明（成功时包含处理的论文数） |
| output_format | string | text |
| data | dict | {"text":"...", "processed_count": int, "dataset": string} |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"成功处理 5 篇论文，汇总报告已保存至数据集目录"}` | 纯文本展示 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| python | >=3.10 | 运行环境 |
| PyPDF2 | 3.0.1 | PDF文本提取（备选：pdfplumber） |
| openai | 1.30.0+ | 调用兼容OpenAI接口的DeepSeek大模型 |
| requests | 2.31.0 | HTTP请求（备用） |
| 系统API | - | 【获取数据集信息】获取数据目录<br>【获取DeepSeek API KEY】获取API密钥 |

## 5. 运行机制

### 5.1 执行流程
1. 接收输入参数 `dataset` 和 `n`。
2. 调用系统API【获取数据集信息】获取数据集 `{dataset}` 的存储目录 `{data_path}`。
3. 调用系统API【获取DeepSeek API KEY】获得 `DEEPSEEK_API_KEY`。
4. 扫描 `{data_path}` 下的所有 `.pdf` 文件：
   - 对每个PDF提取文本内容；
   - 构建提示词，要求DeepSeek v4 Pro生成不超过 `{n}` 字的结构化分析报告（内容包括：标题、作者、总体内容、主要贡献、科研价值、实验过程与结果，分点阐述）；
   - 使用 `openai` SDK（设置 base_url 和 api_key）调用 DeepSeek 模型，获取解析结果。
5. 将每篇论文的分析结果整理为 Markdown 章节，以论文标题作为一级标题，报告内的各分点作为二级子标题。
6. 所有章节合并成一个汇总 `summary.md` 文件，保存至 `{data_path}` 目录下。
7. 返回已处理论文的数量与数据集名称。

### 5.2 错误处理
- **数据集不存在**：记录错误，`status` 返回 `failed`，`message` 说明具体原因。
- **目录中无PDF文件**：返回 0 篇处理数量，`status` 仍为 `success` 但附提示信息。
- **PDF文本提取失败**：跳过该文件，记录日志，继续处理后续文件。
- **DeepSeek API调用失败**（网络错误、额度不足、密钥无效等）：重试1次后若仍失败，则该论文不生成报告，在汇总文件中注明“生成失败”。
- **参数 `n` 为非正整数**：返回参数验证错误。
