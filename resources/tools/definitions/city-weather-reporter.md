# 城市天气预报

## 1. 功能概述
根据用户输入的城市名称，自动查询该城市的实时天气信息，并以结构化表格形式返回降雨量、风速、天气预警、台风预警等关键指标。工具基于免费且无需 API Key 的气象数据接口（如 Open-Meteo）实现，同时可扩展集成其他公开预警数据源。

## 2. 输入规范

| 参数名 | 类型   | 必填 | 默认值 | 说明                     |
|--------|--------|------|--------|--------------------------|
| city   | string | 是   | -      | 城市名称，如“北京”、“上海” |
| lang   | string | 否   | "zh"   | 返回信息的语言，支持 ISO 639-1 代码（如 "en"） |

## 3. 输出规范

### 3.1 标准输出字段
| 字段          | 类型       | 说明                                              |
|---------------|------------|---------------------------------------------------|
| status        | string     | success / failed                                  |
| message       | string     | 结果说明，如“查询成功”或错误原因                  |
| output_format | string     | table                                             |
| data          | dict       | 输出数据，包含天气指标与预警信息                  |

`data` 结构：
```json
{
  "city": "北京",
  "temperature": 24.5,
  "humidity": 65,
  "rainfall": 0.0,
  "wind_speed": 15.3,
  "weather_alerts": [
    {"type": "暴雨", "level": "黄色", "description": "..."}
  ],
  "typhoon_alerts": [
    {"name": "梅花", "status": "远海", "description": "..."}
  ],
  "updated_at": "2026-07-26T10:00:00Z"
}
```

### 3.2 可视化输出格式
| output_format | data 格式                               | 界面渲染方式               |
|---------------|-----------------------------------------|---------------------------|
| `table`       | `{"columns": ["指标","数值"], "rows": [["降雨量","0.0 mm"], ...]}` | 渲染表格，支持多组指标区块 |

## 4. 依赖环境

| 依赖         | 版本     | 用途                           |
|--------------|----------|--------------------------------|
| Python       | ≥ 3.8    | 运行环境                       |
| requests     | ≥ 2.28   | HTTP 请求调用天气 API          |
| geopy        | ≥ 2.3    | 城市名地理编码（转为经纬度）    |
| Open-Meteo   | 免费 API | 核心气象数据（无需 API Key）   |

## 5. 运行机制

### 5.1 执行流程
1. 接收 `city` 参数，通过 `geopy.geocoders.Nominatim` 将城市名称转换为经纬度坐标。
2. 构造 Open-Meteo API 请求（`https://api.open-meteo.com/v1/forecast`），获取当前小时级预报。
3. 从响应中提取降雨量 (`precipitation`)、风速 (`wind_speed_10m`)、温度 (`temperature_2m`)、湿度 (`relative_humidity_2m`) 等。
4. 尝试查询天气预警数据：
   - 可使用其他无需 Key 的公开接口（如中国气象局公开数据），若不可用则 `weather_alerts` 返回空列表，`message` 中注明“暂无预警数据”。
   - 台风预警解析类似，优先使用可用免费源，否则返回空。
5. 将结构化数据封装为 `table` 格式输出，包含所有可用指标。

### 5.2 错误处理
- 城市名称无法找到 → 返回 `status: "failed"`, `message: "未找到城市 '{city}'，请检查名称或使用更具体的地区"`
- 网络请求超时 → 返回 `status: "failed"`, `message: "天气服务暂时不可用，请稍后重试"`
- 数据解析异常 → 返回 `status: "failed"`, `message: "数据格式异常，原始响应: {details}"`
- 完全无降雨/风速数据 → 对应字段填写 0.0，不视作错误
