工具名：论文摘要工具
输入：数据集名{dataset}，摘要长度{n}
过程：
1）通过【获取数据集信息】获取数据集{dataset} 的目录，该目录记录为{data_path}
2）对目录{data_path}中的每个pdf文件论文，抽取文件的论文内容，调用系统统一配置的大模型（LLM）得到一个不超过{n}个字的论文分析报告，分析报告的开始包括论文的标题，作者信息，分析论文总体内容，主要贡献，科研价值，实验过程及结果等方面分点阐述。
3） 所有文件的分析报告合并成一个大的md文件,   其中每篇论文的标题作为章节标题，论文分析内部的章节作为子章节， md文件存放在目录{data_path}下面。

输出：处理的文件的数量， 保存的数据集名{dataset}。

注：LLM 调用由系统统一处理（跟随全局 LLM_PROVIDER / LLM_API_KEY / LLM_MODEL 配置，使用工具模板提供的 _llm_chat 辅助函数），无需自行获取 API KEY。
