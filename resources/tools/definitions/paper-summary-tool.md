# 论文摘要工具

## 1. 功能概述
该工具用于对指定数据集中的论文PDF文件进行自动摘要分析。它通过【获取数据集信息】获取数据集的存储目录，遍历目录中的所有PDF文件，提取论文内容，调用DeepSeek大模型生成包含标题、作者及不超过指定字数的摘要，最终将所有分析结果合并为一个Markdown文件，存放于数据集目录下。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| dataset | string | 是 | - | 数据集名称，用于定位论文PDF目录 |
| n | integer | 否 | 300 | 每篇论文摘要的最大字数 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | text / table |
| data | dict | 输出数据，包含 `file_count`（处理的文件数量）和 `dataset`（数据集名称） |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text": "已处理论文 10 篇，摘要报告已保存至 ..."}` | 纯文本展示 |
| `table` | `{"columns":["字段","值"], "rows":[["处理文件数","10"],["数据集","example_dataset"]]}` | 表格展示 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| python | >=3.9 | 运行环境 |
| openai | >=1.0.0 | 调用DeepSeek API（兼容OpenAI格式） |
| PyPDF2 或 pdfplumber | 最新 | 提取PDF文本内容 |
| requests | 最新 | HTTP请求辅助（openai依赖已包含） |

## 5. 运行机制

### 5.1 执行流程
1. 通过【获取数据集信息】获取数据集 `{dataset}` 的目录 `{data_path}`。
2. 扫描 `{data_path}` 中所有 `.pdf` 文件。
3. 对每个PDF文件：
   - 使用PDF解析库提取全文文本。
   - 通过【获取DeepSeek API KEY】获取API KEY。
   - 调用DeepSeek大模型（如 deepseek-chat），传入论文内容，要求模型返回包含标题、作者及不超过 `{n}` 字摘要的分析文本。
   - 收集各论文的分析结果。
4. 将所有分析结果合并为一个 Markdown 文件（例如 `summaries.md`），保存至 `{data_path}` 目录下。
5. 返回处理结果。

### 5.2 错误处理
- **数据集不存在或无法获取路径** → 返回错误信息，`status` 为 `failed`。
- **PDF解析失败** → 记录错误日志，跳过该文件，继续处理其余文件，最终在消息中说明失败数量。
- **DeepSeek API调用失败（网络、配额、Key无效等）** → 记录错误，跳过当前文件或终止，根据配置返回错误。
- **无PDF文件** → 返回成功但文件数为0，提示未发现PDF。
