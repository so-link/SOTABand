# 测试多模式

## 1. 功能概述

该工具提供两种独立模式：

- **模式 1：2次方函数**：接收一个数值 `x`，返回 `x` 的二次方。
- **模式 2：浏览文件**：接收数值 `x`、`y` 和文件路径 `file_path`，计算 `sin(x) + sin(y)`，将计算结果写入指定文件，并返回计算结果与文件路径。

## 2. 模式定义

### 模式 1：square（2次方函数）

- 模式标识：square
- 描述：接收一个数值 `x`，计算并返回 `x^2`。

#### 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| x | number | 是 | 无 | 需要计算二次方的数值 |

#### 输出规范

| 字段 | 类型 | 说明 |
|------|------|------|
| result | number | `x^2` 的计算结果 |

#### 处理过程

1. 读取输入数值 `x`
2. 校验 `x` 是否为数字类型（int/float）
3. 计算 `result = x ** 2`
4. 返回计算结果

### 模式 2：browse-file（浏览文件）

- 模式标识：browse-file
- 描述：接收数值 `x`、`y` 和文件路径 `file_path`，计算 `sin(x) + sin(y)`，将结果写入文件，并返回计算结果与文件路径。

#### 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| x | number | 是 | 无 | 用于计算 `sin(x)` 的数值 |
| y | number | 是 | 无 | 用于计算 `sin(y)` 的数值 |
| file_path | string | 是 | 无 | 保存计算结果的文件路径 |

#### 输出规范

| 字段 | 类型 | 说明 |
|------|------|------|
| result | number | `sin(x) + sin(y)` 的计算结果 |
| file_path | string | 结果记录写入的文件路径 |

#### 处理过程

1. 读取输入数值 `x`、`y` 和文件路径 `file_path`
2. 校验 `x`、`y` 是否为数字类型，`file_path` 是否为合法路径字符串
3. 计算 `result = sin(x) + sin(y)`
4. 打开或创建 `file_path` 指定的文件
5. 将计算结果写入文件
6. 返回计算结果 `result` 和文件路径 `file_path`

## 3. 输出规范

### 3.1 标准输出字段

| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | text / image / table / file |
| data | dict/list | 输出数据 |

### 3.2 可视化输出格式

| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"..."}` | 纯文本 |
| `image` | `{"image_path":"/path/to/file.png"}` | 直接绘制图片 |
| `table` | `{"columns":[...], "rows":[[...]]}` | 渲染表格 |
| `file` | `{"file_path":"/path/to/result.csv"}` | 下载链接 |

说明：

- 模式 1 返回 `output_format=text`，`data` 中 `text` 字段包含计算结果，如 `{"text": "4"}`。
- 模式 2 返回 `output_format=file`，`data` 中 `file_path` 字段为结果文件路径；计算结果 `result` 同时写入文件并放入 `message` 中返回。

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| Python | >=3.8 | 运行环境 |
| math | 标准库（内置） | 计算 `sin` 函数 |
| os / io | 标准库（内置） | 文件路径校验与文件读写 |

## 5. 运行机制

### 5.1 执行流程

1. 读取调用方指定的模式标识及对应参数
2. 校验必填参数
3. 根据模式标识进入对应模式：
   - 模式 1：计算 `x^2`
   - 模式 2：计算 `sin(x) + sin(y)` 并写入文件
4. 返回统一格式结果

### 5.2 错误处理

- `x` 或 `y` 非数值 → 返回 `status=failed`，`message` 提示参数类型错误
- `file_path` 不合法或目录无写入权限 → 返回 `status=failed`，`message` 提示文件无法写入
- 处理异常 → 捕获并返回详细错误信息
