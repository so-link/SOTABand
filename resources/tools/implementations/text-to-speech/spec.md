# 文字转语音

## 1. 功能概述

将给定的文字内容（`{req}`）转换为自然语音，并保存为音频文件。本工具不使用 Google 语音合成服务，采用本地离线引擎或非 Google 在线服务完成合成。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| req | string | 是 | 无 | 需要转换为语音的文字内容 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | file |
| data | dict | 输出数据，包含音频文件路径 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `file` | `{"file_path":"/path/to/output.mp3"}` | 提供下载链接或播放器 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| pyttsx3 | >=2.90 | 离线文字转语音引擎（不依赖 Google） |
| os | 内置 | 文件路径处理 |

> 注：若选择其他非 Google 在线方案（如 edge-tts），需相应调整依赖。

## 5. 运行机制

### 5.1 执行流程
1. 接收输入文字 `{req}`
2. 校验文字内容不为空
3. 初始化语音合成引擎（使用系统默认 TTS 引擎，非 Google）
4. 将文字转换为语音数据
5. 将语音数据保存为音频文件（格式可为 `.wav` 或 `.mp3`）
6. 构造输出数据，包含文件路径
7. 返回结果

### 5.2 错误处理
- 输入文字为空 → 返回 `status: failed`，提示文字内容不能为空
- 语音引擎初始化失败 → 返回详细错误信息，建议检查系统语音库
- 文件写入失败 → 返回磁盘空间或权限错误描述
