# 数字识别

## 1. 功能概述

采用卷积神经网络实现手写数字识别，支持训练和测试两种模式。  
- **训练模式**：使用 MNIST 数据集训练一个三层卷积神经网络，每一层的隐含节点数为 `n`，训练 `epoch` 轮，输出训练集和测试集上的识别准确率，并保存模型文件。  
- **测试模式**：对输入图片进行必要变换后，加载已保存的模型进行数字识别，输出识别到的数字。  
基于 PyTorch 实现，如检测到可用 GPU 则自动采用 GPU 加速。

## 2. 模式定义

### 模式 1：train（训练模式）

- 模式标识：train
- 描述：使用 MNIST 数据集训练三层卷积神经网络，保存模型并返回训练集、测试集准确率。

#### 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| epoch | int | 是 | 无 | 训练轮次 |
| n | int | 是 | 无 | 每层隐含节点的数目 |

#### 输出规范

| 字段 | 类型 | 说明 |
|------|------|------|
| train_accuracy | float | 训练集上的识别准确率 |
| test_accuracy | float | 测试集上的识别准确率 |
| model_path | string | 保存的模型文件路径 |

#### 处理过程

1. 加载 MNIST 数据集。
2. 构建三层卷积神经网络，每一层的隐含节点数设置为 `n`。
3. 如检测到可用 GPU，则使用 GPU 加速训练。
4. 训练 `epoch` 轮。
5. 计算训练集和测试集上的识别准确率。
6. 保存模型文件并返回结果。

### 模式 2：test（测试模式）

- 模式标识：test
- 描述：对输入图片进行必要变换，加载训练模式保存的模型，输出识别到的数字。

#### 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| file | string | 是 | 无 | 待识别图片文件路径 |

#### 输出规范

| 字段 | 类型 | 说明 |
|------|------|------|
| digit | int | 识别到的数字 |
| confidence | float | 识别置信度 |

#### 处理过程

1. 对输入图片 `file` 进行必要的变换，例如灰度化、缩放、归一化等。
2. 加载训练模式保存的模型。
3. 如检测到可用 GPU，则使用 GPU 加速推理。
4. 对变换后的图片进行数字识别。
5. 输出识别到的数字。

## 3. 输出规范

### 3.1 标准输出字段

| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | text / image / table / file |
| data | dict/list | 输出数据 |

- 训练模式 `data` 格式：`{"train_accuracy": 0.99, "test_accuracy": 0.98, "model_path": "/path/to/model.pth"}`
- 测试模式 `data` 格式：`{"digit": 5, "confidence": 0.97}`

### 3.2 可视化输出格式

| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"..."}` | 纯文本 |
| `image` | `{"image_path":"/path/to/file.png"}` | 直接绘制图片 |
| `table` | `{"columns":[...], "rows":[[...]]}` | 渲染表格 |
| `file` | `{"file_path":"/path/to/result.csv"}` | 下载链接 |

训练模式可使用 `text` 或 `table` 展示准确率；测试模式使用 `text` 展示识别到的数字。

## 5. 运行机制

### 5.1 执行流程

1. 读取输入数据。
2. 校验参数。
3. 根据模式选择执行训练流程或测试流程。
4. 返回处理结果。

### 5.2 错误处理

- 文件不存在 → 返回错误信息，`status=failed`。
- 参数无效 → 返回参数验证错误。
- 模型文件不存在 → 测试模式下返回明确错误信息，提示先执行训练模式。
- 处理异常 → 捕获并返回详细错误信息。
