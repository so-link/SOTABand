# 论文修改建议A

## 1. 功能概述

本工具接收一篇PDF论文路径、投稿会议名称和一个目标数据集名称，自动调用大语言模型对论文进行全面评审，生成详细的中文修改建议报告（Markdown格式），并将报告保存到本地目录；同时自动注册或复用指定的数据集，将评审结果纳入数据集管理。

核心流程：
- 调用【【专利检索与翻译工具】】完成前置处理
- 通过【获取DeepSeek API KEY】获取认证密钥
- 将PDF论文直接传给DeepSeek V4 Pro模型，按给定评估要点（创新性、结构完整性、摘要与章节呼应、实验完备性等）进行评审
- 按{conf}的审稿标准给出最终意见和打分
- 输出评审报告并保存为Markdown文件
- 调用【获取数据集信息】检查数据集，若不存在则通过【数据集注册API】注册新数据集

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| path      | string | 是 | 无 | 待评审PDF论文文件的本地路径 |
| conf      | string | 是 | 无 | 投稿的会议名称，用于匹配评审标准 |
| dataset   | string | 是 | 无 | 评审结果输出数据集名称，用于存储和管理评审报告 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明，例如“评审完成并成功注册数据集” |
| output_format | string | text |
| data | dict | 包含评审意见的文本数据 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"review": "完整的评审意见 Markdown 文本"}` | 纯文本展示 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| requests | ≥2.28.0 | 调用系统API（获取API Key、数据集信息、注册） |
| openai | ≥1.0.0 | 以OpenAI兼容接口调用DeepSeek V4 Pro |
| python-dotenv | ≥1.0.0 | 管理临时环境变量（API Key） |
| pathlib | 内置 | 处理文件路径和目录创建 |
| datetime | 内置 | 生成评审时间戳 |
| hashlib | 内置 | 生成子目录标识（基于论文文件hash） |

## 5. 运行机制

### 5.1 执行流程
1. **前置工具调用**  
   执行【【专利检索与翻译工具】】（根据具体实现可能完成论文元数据提取或预处理，本工具严格按照当前配置原样调用）。

2. **获取认证密钥**  
   调用系统API【获取DeepSeek API KEY】，获取有效的 DeepSeek API Key，并设置为环境变量或配置参数。

3. **论文评审**  
   - 通过 openai 库（兼容 DeepSeek 接口）将 PDF 文件作为文件类型消息直接上传至 DeepSeek V4 Pro 模型。  
   - 构造 system prompt 和 user prompt，要求用中文输出评审意见，涵盖以下10个评估方面：
     (1) 总体创新性评估  
     (2) 结构、形式、实验完整性评估  
     (3) 摘要、简介与章节安排的一致性与连贯性  
     (4) 总体思路章节与技术点的一致性  
     (5) 公式目的与符号解释  
     (6) 消融实验与核心参数敏感性分析  
     (7) 实验充分性与 baseline 先进完备性  
     (8) 可读性与可复现性  
     (9) 针对上述重点的详细批改建议和指引  
     (10) 按{conf}评审标准进行评议和打分  
   - 评审时间使用系统当前时间。

4. **保存评审报告**  
   - 根据论文文件内容生成唯一标识（如 SHA256 哈希），构建子目录路径 `./data/papers/{xxxx}/`（xxxx 为哈希前8位）。  
   - 在该目录下创建 Markdown 文件，文件命名格式：`review_{timestamp}.md`，写入完整的评审意见。  
   - 记录该目录路径供后续数据集注册使用。

5. **数据集注册**  
   - 调用系统API【获取数据集信息】查询数据集 `{dataset}` 是否存在。  
   - 若不存在，则调用系统API【数据集注册API】，将目录 `./data/papers/{xxxx}/` 注册为数据集 `{dataset}`；若已存在，则记录日志并跳过注册。  
   - 将评审报告的存储路径与数据集关联。

6. **返回结果**  
   将 Markdown 格式的评审意见作为文本装入 `data.review` 字段返回。

### 5.2 错误处理
- 文件不存在或无法读取 → 返回 `status: failed`，`message` 说明具体文件错误。
- 无法获取 API Key → 返回错误信息，中断后续流程。
- DeepSeek 调用失败（网络、额度、模型不支持等）→ 捕获异常，返回详细错误原因。
- 子目录创建失败 → 返回错误并终止。
- 数据集查询或注册 API 异常 → 返回对应的失败信息，已保存的评审报告仍正常输出，但需在 message 中提示数据集操作失败。
