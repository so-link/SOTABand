# 图片查看器

## 1. 功能概述

根据输入的图片文件路径，读取并返回对应的图片内容，供界面直接渲染展示。适用于本地图片文件的快速预览。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| path | string | 是 | - | 图片文件的本地路径（绝对路径或相对于执行目录的相对路径） |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | image |
| data | dict | 输出数据，包含图片路径 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `image` | `{"image_path":"/path/to/file.png"}` | 直接绘制图片 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| Pillow | >=9.0.0 | 验证图片文件的有效性，避免读取非图片文件 |

## 5. 运行机制

### 5.1 执行流程
1. 接收输入的图片文件路径
2. 校验路径不为空且文件存在
3. 使用 Pillow 尝试打开文件，验证是否为有效的图片格式
4. 若验证通过，返回包含图片路径的标准输出；若失败则返回错误信息

### 5.2 错误处理
- 文件不存在 → 返回 `status: failed`，`message` 提示文件不存在
- 文件不是有效图片 → 返回 `status: failed`，`message` 提示无效的图片格式
- 其他处理异常 → 捕获异常，返回详细错误信息
