# 统计指定文件夹下的文件数量

## 1. 功能概述

统计指定文件夹下直接包含的文件数量，不递归统计子文件夹内的文件。适用于快速查看某个目录中的文件总数。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| dir | string | 是 | 无 | 目标文件夹路径 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | text / image / table / file |
| data | dict/list | 输出数据 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"文件夹下文件数量：123"}` | 纯文本 |

成功时示例：
```json
{
  "status": "success",
  "message": "统计完成",
  "output_format": "text",
  "data": {
    "text": "文件夹下文件数量：123"
  }
}
```

失败时示例：
```json
{
  "status": "failed",
  "message": "文件夹不存在：/invalid/path",
  "output_format": "text",
  "data": {
    "text": "统计失败"
  }
}
```

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| Python | >=3.6 | 运行环境，使用标准库 os |

## 5. 运行机制

### 5.1 执行流程
1. 读取输入数据中的文件夹路径 `dir`
2. 校验 `dir` 是否存在且为文件夹
3. 使用 `os.listdir()` 遍历目录，统计文件数量（排除子目录）
4. 返回统计结果

### 5.2 错误处理
- 文件夹不存在 → 返回错误信息：`文件夹不存在：{dir}`
- 路径不是文件夹 → 返回验证错误：`路径不是文件夹：{dir}`
- 权限不足 → 捕获异常并返回详细错误信息
