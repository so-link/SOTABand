# 图片黑白转换

## 1. 功能概述

将输入图片转换为黑白（灰度）图像，并保存为新文件，返回新图片的路径，供界面直接绘制。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| file | string | 是 | 无 | 输入图片的文件路径 |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | image |
| data | dict | 返回图片路径，格式为 {"image_path": "/path/to/output.png"} |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `image` | `{"image_path":"/path/to/file.png"}` | 直接绘制图片 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| Pillow | >=9.0 | 图像读写及颜色空间转换 |
| python | >=3.8 | 运行环境 |
| os | 内置 | 路径处理与文件存在性检查 |

## 5. 运行机制

### 5.1 执行流程
1. 检查输入文件是否存在
2. 使用 PIL 读取图片
3. 调用 `.convert('L')` 转换为灰度图
4. 将结果保存到临时目录或指定输出路径
5. 返回输出图片的路径及状态

### 5.2 错误处理
- 文件不存在 → 返回 `status: failed`，`message: "输入文件不存在"`
- 参数无效 → 返回 `status: failed`，`message: "参数file不能为空"`
- 图片处理异常 → 捕获异常并返回详细错误信息，如 `"图片处理失败: ..."`
