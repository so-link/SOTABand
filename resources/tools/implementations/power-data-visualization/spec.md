# 电力数据可视化

## 1. 功能概述

读取 CSV 文件指定列和指定行范围的数据，绘制时序曲线，并输出曲线图片。

## 2. 输入规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| path | string | 是 | 无 | CSV 文件路径 |
| n | integer | 是 | 无 | 列编号，从 1 开始 |
| start | integer | 是 | 无 | 起始行号（数据行，不含表头，从 1 开始） |
| end | integer | 是 | 无 | 结束行号（数据行，不含表头，从 1 开始） |

## 3. 输出规范

### 3.1 标准输出字段
| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | success / failed |
| message | string | 结果说明 |
| output_format | string | text / image / table / file |
| data | dict/list | 输出数据 |

### 3.2 可视化输出格式
| output_format | data 格式 | 界面渲染方式 |
|---------------|----------|-------------|
| `text` | `{"text":"..."}` | 纯文本 |
| `image` | `{"image_path":"/path/to/file.png"}` | 直接绘制图片 |
| `table` | `{"columns":[...], "rows":[[...]]}` | 渲染表格 |
| `file` | `{"file_path":"/path/to/result.csv"}` | 下载链接 |

## 4. 依赖环境

| 依赖 | 版本 | 用途 |
|------|------|------|
| pandas | >=1.5.0 | 读取 CSV 文件 |
| matplotlib | >=3.5.0 | 绘制时序曲线 |

## 5. 运行机制

### 5.1 执行流程
1. 读取输入数据：根据 path 读取 CSV 文件
2. 校验参数：检查文件是否存在、列编号是否有效、起始行和结束行是否合法
3. 执行核心逻辑：提取第 n 列第 start 到 end 行数据，按行顺序绘制时序曲线，并保存为 PNG 图片
4. 返回结果：返回包含图片路径的输出数据

### 5.2 错误处理
- 文件不存在 → 返回错误信息
- 列编号无效 → 返回验证错误
- 起始行或结束行超出范围 → 返回验证错误
- 数据非数值类型 → 返回错误信息
- 处理异常 → 捕获并返回详细错误
